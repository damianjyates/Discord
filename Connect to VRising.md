🔐 Connect to YES WireGuard VPN

This guide provides step-by-step instructions for setting up and connecting to the YES WireGuard VPN on Linux and Windows. The VPN allows secure access to our internal network (10.1.1.0/24) — including the V Rising game server.

📋 Prerequisites

You'll need a WireGuard-compatible client installed

Your public key must be shared with the administrator (we use this to authorize your connection)

🐧 Linux Instructions

1. Install WireGuard

On most Debian-based systems (Ubuntu, etc.):

```bash
sudo apt update
sudo apt install wireguard -y
```

For RHEL/Fedora:

```bash
sudo dnf install wireguard-tools
```

2. Generate a Key Pair

```bash
wg genkey | tee client_private.key | wg pubkey > client_public.key
```

- client_private.key — Keep this secret, never share it

- client_public.key — Send this to the VPN administrator

3. Create a Config File
Create a file named wg0.conf:

```ini
[Interface]
PrivateKey = <your-private-key>
Address = 10.13.13.2/24
DNS = 1.1.1.1

[Peer]
PublicKey = <server-public-key>
Endpoint = <server-public-ip>:51820
AllowedIPs = 10.1.1.0/24, 10.13.13.0/24
PersistentKeepalive = 25
```

Replace:

- <your-private-key> with contents of client_private.key

- <server-public-key> and <server-public-ip> — provided by the admin

4. Connect

```bash
sudo wg-quick up wg0
```

To disconnect:

```bash
sudo wg-quick down wg0
```

🪟 Windows Instructions

1. Install WireGuard for Windows
Download from the official site:
🔗 https://www.wireguard.com/install/

2. Create a Tunnel
- Open the WireGuard app

- Click "Add Tunnel" → "Add Empty Tunnel"

- WireGuard will generate your private and public keys

- Copy your public key and send it to the admin

- Enter your configuration details:

```ini
[Interface]
PrivateKey = <auto-generated>
Address = 10.13.13.2/24
DNS = 1.1.1.1

[Peer]
PublicKey = <server-public-key>
Endpoint = <server-public-ip>:51820
AllowedIPs = 10.1.1.0/24, 10.13.13.0/24
PersistentKeepalive = 25
```

Replace <server-public-key> and <server-public-ip> with values from your admin.

3. Activate the VPN
- Click Activate to connect

- Once connected, you can reach internal systems such as:

  - 10.1.1.200:9876 (V Rising server)

  - Shared services and systems
